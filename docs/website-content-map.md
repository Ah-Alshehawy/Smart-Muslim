## 4. Frequently Asked Questions (FAQ)

1. **هل التطبيق مجاني بالكامل؟ / Is the app 100% free?**  
   نعم، التطبيق مجاني بالكامل بكافة خصائصه ومتاح للجميع دون أي رسوم، وهو صدقة جارية.
2. **هل يحتوي التطبيق على إعلانات؟ / Does it contain ads?**  
   لا، التطبيق خالٍ تماماً من أي إعلانات تجارية ولن يتم وضع أي إعلانات به مستقبلاً حفاظاً على قدسية العبادة.
3. **هل يتم تتبع بيانات المستخدم أو بيعها؟ / Is user data tracked or sold?**  
   قطعاً لا. لا نستخدم أي مكتبات تتبع أو تحليلات (Zero Analytics)، وموقعك الجغرافي لا يغادر هاتفك أبداً.
4. **هل يعمل التطبيق دون اتصال بالإنترنت؟ / Does it work offline?**  
   نعم، جميع الحسابات ومحتوى القرآن الكريم والأذكار مدمجة ومخزنة محلياً لتعمل معك في أي وقت ومكان.
5. **كيف أقوم بتثبيت التطبيق على جهاز الأيفون (iOS)؟ / How to install on iOS?**  
   يمكن فتح النسخة الخفيفة (PWA) عبر متصفح Safari، ثم الضغط على زر المشاركة واختيار "إضافة إلى الصفحة الرئيسية".
6. **ما هو رابط تحميل نسخة الأندرويد؟ / What is the Android download link?**  
   يمكن تحميل حزمة APK المباشرة المحدثة عبر الرابط الرسمي المعتمد في مركز التحميل.
